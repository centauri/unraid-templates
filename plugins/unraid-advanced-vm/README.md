**Unraid Advanced VM**

Manage VM hardware, storage and networking, schedule backups and restore snapshots from the Unraid WebGUI.

## Installation and support

For this beta, paste the following URL into **Plugins → Install Plugin**. Community Applications availability depends on its review and indexing process. Use **Plugins → Check for Updates** for later releases.

```text
https://raw.githubusercontent.com/centauri/unraid-templates/main/plugins/unraid-advanced-vm/unraid-advanced-vm.plg
```

Open **VMs → Advanced VM**. Choose a mounted pool under **Settings → Storage** before enabling VM changes. Inspect interrupted operations in **Tasks** before retrying.

Include the plugin version, Unraid version and the affected action when reporting a problem. [Support](https://github.com/centauri/unraid-templates/issues)
